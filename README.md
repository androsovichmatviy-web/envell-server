# Энвелл — онлайн на 5 игроков

Фанатская 2D-игра по мотивам «Героев Энвелла». Настоящий мультиплеер: игра считается
на сервере, друзья заходят по ссылке из интернета.

- До 5 человек в комнате, свободных героев берут боты
- 100 уровней, каждый 10-й — усиленный страж, на 100-м Моргарт в трёх фазах
- Общий чат, респаун, общий выбор уровня и сложности

Четыре файла, все в одной папке, без подпапок:

```
package.json
server.js
index.html
README.md
```

## Запуск с телефона (Android), без компьютера

Всё делается в браузере, терминал не нужен, ссылка получится постоянная.

### Шаг 1. Сохрани файлы

Скачай все четыре файла на телефон. Они лягут в «Загрузки».

### Шаг 2. Заведи GitHub

Открой `github.com`, зарегистрируйся бесплатно, подтверди почту.

### Шаг 3. Создай репозиторий

- Кнопка `+` сверху → **New repository**
- Name: `envell-server`
- Выбери **Public**
- **Create repository**

### Шаг 4. Загрузи файлы

На странице пустого репозитория найди ссылку **uploading an existing file**.
Нажми **choose your files**, выбери сразу все четыре файла из «Загрузок».
Внизу зелёная кнопка **Commit changes**.

Важно: все четыре файла лежат в корне, папки создавать не надо.

### Шаг 5. Подключи Render

- Открой `render.com`, войди через **Sign in with GitHub**
- **New +** → **Web Service**
- Выбери репозиторий `envell-server` → **Connect**
- Заполни:
  - Language: **Node**
  - Build Command: `npm install`
  - Start Command: `npm start`
  - Instance Type: **Free**
- **Create Web Service**

Жди 2–3 минуты, пока в логах не появится строка про запуск сервера.
Сверху будет адрес вида `https://envell-server-xxxx.onrender.com`.

### Шаг 6. Зови друзей

Кидаешь им ссылку. Каждый:

1. Вводит своё имя
2. Вводит **одинаковый код комнаты** (по умолчанию `ENVELL`)
3. Берёт свободного героя
4. Кто угодно жмёт «Начать бой»

Пустые слоты берут боты, так что играть можно хоть вдвоём.
Разные коды комнат — разные независимые игры на одном сервере.

### Про бесплатный тариф

Если минут 15 никто не заходил, Render усыпляет сервис. Первый заход после паузы
грузится секунд 30–50, это нормально, дальше быстро.

## Если появится компьютер

```
npm install
npm start
```

Игра на `http://localhost:3000`. Для друзей из интернета — туннель:

```
npx cloudflared tunnel --url http://localhost:3000
```

Выдаст временную публичную ссылку, живёт пока открыт терминал.

## Управление

- Движение: палец по полю (появится джойстик) или WASD / стрелки
- Атака автоматическая по ближайшему врагу
- Кнопка снизу или пробел — способность
- Поле внизу — чат команде

## Герои

| Герой | Роль | Способность |

| Арт | воин | Рывок с уроном по площади |
| Кира | лучница | Залп во все стороны |
| Вик | страж | Щит на всю команду |
| Фил | маг | Взрыв по области |
| Ларс | бард | Лечение всей команды |

## Как это устроено

`server.js` считает игру 60 раз в секунду и рассылает состояние 20 раз в секунду.
`index.html` только рисует и шлёт нажатия. Поэтому читы в браузере не работают:
клиент отправляет лишь направление движения и нажатие способности.
